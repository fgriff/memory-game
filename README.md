Игра «Memory Game» на чистом JavaScript и SCSS. 16 карточек, 8 пар, счётчик ходов, таблица лидеров в `localStorage`. Без фреймворков и UI-библиотек.

## Правила игры

1. На поле 16 карточек, 8 пар одинаковых изображений. Все рубашкой вверх.
2. Игрок открывает две карточки за ход.
3. Если картинки совпали — обе остаются открытыми до конца игры, счётчик пар растёт.
4. Если не совпали — обе видны ~1 секунду и закрываются. Пока они открыты, другие карточки выбрать нельзя.
5. За ход считается открытие двух карточек (могут совпасть или нет). Клик только по одной за ход не засчитывается.
6. Игра заканчивается, когда найдены все 8 пар. Открывается модальное окно с числом ходов.
7. Результат попадает в таблицу лидеров. В ней — до 10 лучших игр.

## Как запустить
#### 1. Клонировать репозиторий

```bash
git clone https://github.com/fgriff/memory-game.git
```

#### 2. Перейти в склонированную папку репозитория

```bash
cd memory-game
```

#### 3. Перейти в ветку проекта

```bash
git checkout memory-game
```

#### 4. Перейти в папку проекта

```bash
cd memory-game
```

#### 5. Установить зависимости

```bash
npm i
```

#### 6. Запустить проект

```bash
npm run dev
```

Vite откроет игру на `http://localhost:5173` (по умолчанию).

## Стек

- **JavaScript** — ES-модули, классы, приватные поля (`#field`).
- **SCSS** — переменные, БЭМ-нейминг.
- **Vite** — сборщик и dev-сервер.
- **localStorage** — хранение таблицы лидеров.

Без React, Vue, jQuery и любых UI-библиотек. Только стандартные средства браузера.

## Архитектура

Проект разделён на слои. Каждый слой знает только о своём:

```
┌──────────────────────────────────────────────┐
│  main.js      — точка входа                  │
├──────────────────────────────────────────────┤
│  App          — связывает всё вместе         │
├──────────────────────────────────────────────┤
│  components/  — «вид»: Header, Board, Card,  │
│                 Counter, Modal, ...          │
├──────────────────────────────────────────────┤
│  game/        — «мозг»: Game                 │
├──────────────────────────────────────────────┤
│  services/    — данные и хранение:           │
│                 Deck, Leaderboard, Storage   │
├──────────────────────────────────────────────┤
│  core/        — фундамент: Element, EventBus │
└──────────────────────────────────────────────┘
```

**Ключевая идея:** «вид» не решает, что происходит в игре, он только отображает и сообщает о действиях. Решает `Game`. `App` — переводчик между ними.

Зачем так делать? Если завтра поменяется внешний вид (например, карточки станут круглыми), то логика не затронется. И наоборот: поменяешь правила (ход = открытие трёх карточек) — не тронешь вёрстку.

### Роли классов

| Класс | Роль |
|---|---|
| `Element` | Базовый класс для всего, что рисуется. Создаёт DOM-узел, вешает классы, слушатели, умеет удалять себя. |
| `EventBus` | Шина событий. `Game` эмитит события, `App` слушает. Они не знают друг о друге. |
| `Game` | «Мозг». Правила: ходы, пары, таймер, победа. Не знает про DOM. |
| `Card` | Одна карточка. Состояние: открыта / найдена / заблокирована. Методы: `flip`, `unflip`, `match`, `reset`. |
| `Board` | Поле 4×4. Создаёт 16 `Card` из колоды. |
| `Counter` | Счётчики ходов и пар. |
| `Header` | Две кнопки: «Новая игра» и «Таблица лидеров». |
| `Modal` | Общая оболочка модальных окон (оверлей, Escape, блокировка скролла). |
| `VictoryModal` | Содержимое модалки победы. |
| `LeaderboardModal` | Содержимое таблицы лидеров. |
| `Deck` | Генератор колоды: 8 случайных картинок + перемешивание. |
| `Leaderboard` | Сортировка, топ-10, добавление результата. |
| `Storage` | Обёртка над `localStorage`. |
| `App` | Связывает `Game`, UI и модалки. Единственное место, где они встречаются. |

## Технические ограничения

Приложение соответствует требованиям задания:

- **`body` в `index.html` пустой.** Вся разметка создаётся через `document.createElement` в JS.
- **Запрещены** `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `DOMParser`, `Range.createContextualFragment`.
- **Запрещены** `alert`, `confirm`, `prompt` — вместо них модальные окна.
- **Без сторонних библиотек** для UI и игровой логики. Только стандартные возможности браузера.
- **Очистка DOM** — через `firstChild.remove()`, а не `innerHTML = ''`.
